BirdNET 3.0 + Geo · Manual Web

Aplicación estática, gratuita, con inferencia en el navegador. El audio no se envía a un servidor de predicción.

Inicio rápido

Abre la URL publicada en GitHub Pages. Sube tu audio: el análisis se inicia sin necesidad de pulsar «Analizar». Durante el trabajo se muestra el progreso en el lugar donde luego se ve el nombre del archivo.

Audio y progreso

El progreso informa de descarga del modelo, preparación del motor, análisis por ventanas y Geo. Al finalizar reaparece el nombre y tamaño del WAV. Puedes seleccionar otro archivo sin reiniciar la página.

Modelos y GPU

Los modelos ONNX se sirven desde GitHub Pages. Por defecto el navegador intenta ejecutar mediante WebGPU, pasando a WASM/CPU si faltan operadores o compatibilidad. Marca «Conservar modelos» para guardarlos en IndexedDB; el navegador podría eliminar cachés por espacio. Si hace falta, selecciona archivos ONNX y etiquetas manualmente.

Metadatos y Geo

Se reconocen patrones como 20240914T070000-0500_PEC [-04.65337-079.00895].wav y P-BLACKT_20260419_060002_30.wav. Se lee fecha/hora, UTC−05:00 si no hay zona, y coordenadas cuando existen. El último sufijo sin semántica no se interpreta. Puedes editar todo y repetir análisis.

Espectrograma

Al hacer zoom por recuadro se calcula nuevamente la FFT del fragmento visible desde las muestras originales. Clic posiciona cursor, arrastre crea selección, rueda aplica zoom, Shift+rueda zoom frecuencial; «Ver todo» restaura ambos ejes. Eje Y puede ser lineal/Mel y las marcas se muestran en Hz enteros.

Detecciones

La tabla tiene scroll independiente del espectrograma y encabezados ordenables. Clic en fila resalta el intervalo; ▶ reproduce solo desde el inicio de la fila y se vuelve ❚❚ para pausar. Modos Ventanas y Agrupadas. Los intervalos agrupados son aproximaciones de actividad, no anotaciones precisas de cada sílaba.

Exportaciones

TXT Audacity: columnas inicio, fin, etiqueta separados por tabulaciones; texto como Scytalopus micropterus 0.86. CSV incluye acústico y Geo separados con plena precisión. El score acústico no es una probabilidad ecológica calibrada.

Diagnóstico

Ante un error, la tarjeta de audio muestra el fallo y abre el diagnóstico con su texto. «Descargar log» crea un archivo local en tu navegador. GitHub Pages no dispone de servidor para escribir un log central; todo el historial pertenece a la sesión del navegador.

Publicación

Sube el proyecto a una rama main y activa GitHub Actions como fuente de Pages. El flujo descarga los ONNX en el momento del despliegue y publica el sitio junto con ellos. Puedes comprobar la ejecución antes en localhost:8000. Ver README para instrucciones exactas.
