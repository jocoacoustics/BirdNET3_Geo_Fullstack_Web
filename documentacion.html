BirdNET 3.0 + Geo Web

Aplicación estática; audio e inferencia permanecen en el equipo del usuario. La primera carga de librerías y modelos requiere conexión.

Inicio rápido

Versión comprobable: la interfaz debe decir Web v0.2.2 y la primera línea de Diagnóstico debe mostrar BirdNET3_Geo_Fullstack_Web v0.2.2, URL, navegador y WebGPU.

Abre el sitio en GitHub Pages y usa Subir / cambiar audio. La inferencia comienza automáticamente. La tarjeta muestra la descarga de modelos y el procesamiento; al finalizar, reaparece el nombre del archivo.

Modelos oficiales

En v0.2.2 no se publica una carpeta de pesos ONNX en GitHub. El navegador busca los siguientes recursos según config.yaml:

RecursoOrigen
BirdNET acústico Preview 3.1 FP16 prunedZenodo BirdNET
Etiquetas acústicas Preview 3.1Zenodo API, mismo registro
BirdNET Geo ONNX FP16Demo oficial Geo
Etiquetas GeoDemo oficial Geo

La taxonomía completa es opcional. El modelo Geo solo se descarga si hay coordenadas y semana válidas.

Conservar modelos en el navegador

El casillero Conservar modelos viene activado. La opción se recuerda en posteriores visitas, y los archivos se guardan en IndexedDB. Con Comprobar caché revisas los recursos almacenados; Limpiar caché elimina estas copias. Proteger caché solicita almacenamiento persistente; el navegador puede denegar la petición y puede eliminar datos cuando se limpia el sitio o falta espacio.

Los audios no se guardan en IndexedDB. Si desmarcas Conservar, no se leerán ni escribirán archivos de modelos persistentes, pero las copias anteriores permanecen hasta Limpiar caché.

Si una descarga oficial falla

La v0.2.2 utiliza la API /api/records/.../files/.../content de Zenodo en vez de la URL HTML que puede bloquear CORS. El log señala etapa, URL y respuesta. Un error CORS no significa que el modelo sea incorrecto: el servidor remoto puede impedir que un script de otro dominio acceda a su respuesta. Abre Diagnóstico o descarga el registro. Para recuperar el flujo, descarga desde Zenodo oficial el ONNX acústico FP16 pruned y su archivo Labels.csv; en Modelos ONNX → Archivos locales alternativos selecciónalos y vuelve a pulsar Analizar. Si Conservar está activado, los archivos seleccionados también se guardan automáticamente en IndexedDB y pueden reutilizarse la próxima vez. Para Geo, utiliza su demo oficial.

Inferencia y progreso

Ventana inicial de 5 segundos, solapamiento de 1, Top K de 100, umbral de inferencia 0.01, vista 0.10. Puedes ajustar en la interfaz los parámetros y pulsar Analizar para recalcular. WebGPU se intenta primero; CPU-WASM funciona como alternativa cuando un operador no es compatible.

Metadatos y Geo

P-BLACKT_20260419_060002_30.wav genera fecha 2026-04-19, hora 06:00:02 y zona −05:00. El sufijo _30 se ignora. Puedes editar los valores. Sin latitud y longitud, el modelo acústico sigue funcionando y Geo se omite. El score Geo se conserva separado del score acústico.

Espectrograma

Zoom por recuadro con arrastre. Clic simple posiciona el cursor de reproducción; rueda acerca o aleja en tiempo y Shift+rueda en frecuencia. Ver todo devuelve la vista original. Escala Y Mel o lineal; marcas de frecuencia en Hz enteros sin cuadrícula horizontal. Al ampliar se recalcula una STFT sobre el audio original.

Detecciones

Tabla independiente con columnas ordenables y búsqueda por especie. Clic en fila destaca el intervalo sobre el espectrograma; ▶ reproduce desde el inicio del segmento y ❚❚ permite pausar. La vista Agrupadas crea regiones temporales aproximadas, no límites exactos de vocalización.

Exportaciones

CSV con scores acústico y Geo. TXT Audacity con tres columnas tabuladas, sin cabecera, inicio/fin en segundos y etiqueta científica con score de dos decimales: Tinamus osgoodi 0.86.

Publicación

Haz push con GitHub Desktop y deja Settings → Pages → Source = GitHub Actions. El workflow .github/workflows/pages.yml publica solo HTML, CSS, JS, configuración y manual; no intenta descargar ONNX ni servir archivos models/*.onnx. Tras una actualización haz recarga forzada para renovar JS y YAML.

Se ha comprobado el código y el flujo con modelos simulados. La descarga directa real desde las fuentes oficiales, su CORS y la inferencia científica deben verificarse en GitHub Pages.
